# AGENTS.md

If you are an AI agent and a human asked you to install or set up **BabyZilla**
(the OpenCode context-compression plugin) from this repository:

**Read `AGENT-INSTALL.md` and execute it step by step.**

- Follow the steps in order. Verify each step before moving on.
- Every step has an explicit verification command and an expected result.
- If any verification fails, STOP and report exactly what failed plus the last
  command's output. Do not improvise around a failing step.

Do not read the whole repository first — `AGENT-INSTALL.md` is the procedure;
the other docs (`README.md`, `docs/`) are optional background reading.
